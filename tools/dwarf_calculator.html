DWARF Hyperparameter Calculator

Refreshed for current DWARF recipe families: legacy FA-anchored DSQG, triadic J=96 variants, and newer HISA/DSR layouts. This tool is now explicitly recipe-driven instead of pretending one formula fits every era of the repo.

Important: the parameter math here is intentionally approximate for sparse-specific extras. Dense core counts are solid; DSQG / DSR / HISA routing overhead depends on the exact script and kernel version. Use this for planning, not for claiming an exact model-size integer.
